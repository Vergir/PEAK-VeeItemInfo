# VeeItemInfo

This overlay shows what the thing in your hands does, right above the inventory slot holding it.

![The overlay above the held item](https://raw.githubusercontent.com/Vergir/PEAK-VeeItemInfo/master/docs/screenshots/antidote.jpg)

Last updated for and tested on **PEAK 2.4.c**.

## See it for every item

**[Every item's overlay, exactly as it draws in game →](https://vergir.github.io/PEAK-VeeItemInfo/showcase.html)**

That page is generated by the mod itself, so it is the honest answer to "what will this
tell me?" before you install anything.

## What it shows

Four sections, each of which you can switch off:

- **Item-specific facts** — how far a Rope Cannon reaches, how long a stovetop burns, what
  an item does while you merely hold it.
- **Effects** — every status change, whether it lands on you or on everyone nearby.
- **Cooking** — whether cooking improves the item, ruins it, or turns it
  into an explosion.
- **Weight**.

## Configuration

![The settings menu](https://raw.githubusercontent.com/Vergir/PEAK-VeeItemInfo/master/docs/screenshots/config.png)

- **Sections** — turn on or off item weight, status changes, or other sections.
- **Appearance** — font size, outline, line spacing, icon sharpness, box width,
  and where the overlay sits relative to the slot.
- **Formatting** — what a full status bar counts as (set it to 40 and a Granola Bar reads 6
  instead of 15), and Unity units instead of PEAK metres.
- **Item Info** — the Shroomberry colour hint, settings for revealing spoiler info and which figure the Rope Cannon shows.
- **Advanced** — the once-a-second re-check, which is what lets you read an item in another
  player's hands as they swap it, and debug logging.
